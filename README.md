# Dom2API

Dom2API 是一款 Windows 桌面 AI API 转发与调试工具，将多个上游账号接入统一的本地地址，并在上游失败或响应超时时尝试其他账号。它支持查看对话、HTTP 请求与 SSE 流式事件，统计请求耗时和 Token 用量，并导出网络记录。

## 使用方法

1. 运行 `Dom2API.exe`，点击“添加账号”，填写上游 API 基址（如 `https://api.openai.com/v1`）和 API 密钥；需要时可为账号设置 Socks5 代理。
2. 启用至少一个账号，设置监听端口（默认 `1020`），点击“启动服务”。可按需调整响应超时阈值（默认 30 秒）和调度周期（默认 10 分钟）。
3. 在 AI 客户端中，将 API Base URL 设置为 `http://127.0.0.1:1020/v1`，模型名称填写上游支持的模型。若客户端要求 API Key，可填写任意非空占位值；转发时会使用所选上游账号的密钥。修改监听端口后，请同步修改客户端地址。
4. 发起对话后，在“消息”页查看对话内容，在“网络”页查看请求、响应及流式事件；需要排查问题时，在“调试”页点击“导出所有网络记录”。
5. 使用完毕后点击“停止服务”。如需下次沿用配置，可勾选“记住连接配置和账号”；也可进一步启用“登录 Windows 时自动运行”。

如需从站点导入账号，点击“同步账号”→“添加站点”，填写站点网址及登录信息；支持自动识别 Sub2API 和 New API，再将所需 API 密钥“添加到本地”。

服务仅监听本机地址。启用“记住连接配置和账号”后，配置会保存在程序目录的 `Dom2API.settings.json`，其中包含明文 API 密钥和站点密码。

## 从源码运行

在 Windows 上安装 .NET 10 SDK，然后在仓库根目录执行：

```powershell
dotnet run --project .\Dom2API\Dom2API.csproj
```

发布为自带运行时的 Windows x64、x86 和 ARM64 单文件程序（需要 Git）：

```powershell
.\publish.ps1
```

发布结果统一放在 `publish` 目录，目标电脑无需另行安装 .NET 运行时。也可指定一个或多个架构：

```powershell
.\publish.ps1 -Architecture arm64
.\publish.ps1 -Architecture x64,x86
```

发布版本取当前提交历史中最近的 `v*` Git 标签，没有可用版本标签时，脚本会报错；构建前需确保已拉取相关标签和提交历史。
