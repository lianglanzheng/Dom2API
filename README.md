# Dom2API

Dom2API 是一款 Windows 桌面 AI API 转发与调试工具，将多个上游账号接入统一的本地地址，并在上游失败或响应超时时尝试其他账号。它支持查看对话、HTTP 请求与 SSE 流式事件，统计请求耗时和 Token 用量，并导出网络记录。

## 使用方法

1. 运行 `Dom2API.exe`，点击“添加账号”，填写上游 API 基址（如 `https://api.openai.com/v1`）和 API 密钥；需要时可为账号设置 Socks5 代理。
2. 启用至少一个账号，设置监听端口（默认 `1020`），点击“启动服务”。可按需调整响应超时阈值（默认 30 秒）和调度周期（默认 10 分钟）。
3. 在 AI 客户端中，将 API Base URL 设置为 `http://127.0.0.1:1020/v1`，模型名称填写上游支持的模型。若客户端要求 API Key，可填写任意非空占位值；转发时会使用所选上游账号的密钥。修改监听端口后，请同步修改客户端地址。
4. 发起对话后，在“消息”页查看对话内容，在“网络”页查看请求、响应及流式事件；需要排查问题时，在“调试”页点击“导出所有网络记录”。
5. 使用完毕后点击“停止服务”。如需下次沿用配置，可勾选“记住连接配置和账号”；也可进一步启用“登录 Windows 时自动运行”。

如需从站点导入账号，点击“同步账号”→“添加站点”，填写站点网址及登录信息；支持自动识别 Sub2API 和 New API，再将所需 API 密钥“添加到本地”。

添加或编辑账号时，可填写“模型过滤”正则表达式。留空表示不限制；例如 `^(gpt-|claude-)` 允许这两类模型，`^gpt-4o$` 仅允许指定模型。默认区分大小写，可用 `(?i)` 忽略大小写。调度会先匹配 JSON 请求正文的 `model` 字段，再按健康状态、倍率和账号顺序选择上游；失败重试及超时追加账号也遵循此规则。未指定模型的请求（如 `/v1/models`）不受限制；无匹配的启用账号时返回 HTTP 503。非法正则无法保存，匹配超时视为不匹配。过滤规则随账号配置保存，旧配置默认不限制模型。

账号管理中，“同步账号”左侧的预设下拉菜单可立即切换各账号的启用状态，服务运行时也可切换。点击“新建”保存当前启用情况；调整账号开关后，点击“修改”可更新预设及名称，也可取消“以当前账号启用情况更新此预设”以仅重命名。“恢复”可撤销当前启用情况相对预设的修改；“删除”仅移除预设，保留当前账号状态。预设按账号标识匹配，不受账号改名和排序影响；切换时，预设中未记录的新账号默认禁用，已删除账号的记录会忽略。勾选“记住连接配置和账号”后，预设与当前选择会一并保存。

账号可设置“手动倍率”（默认 `1`，支持 `0` 及非负小数）和“自动检测倍率”（默认开启）。开启时先查询 Sub2API，再尝试 New API 站点，全部失败后回退到手动倍率；关闭时不发起倍率查询，直接使用手动值，倍率刷新按钮也会禁用。界面展示和调度排序使用同一生效倍率，可通过倍率提示查看来源和检测失败原因。修改后立即生效，勾选记住配置后随账号保存。

服务仅监听本机地址。启用“记住连接配置和账号”后，配置会保存在程序目录的 `Dom2API.settings.json`，其中包含明文 API 密钥和站点密码。

每次启动软件时会在后台查询 GitHub Latest 正式版，并通过 NuGet.Versioning 与本地版本比较（忽略提交哈希）。发现新版本后，“调试”页的“关于 Dom2API”会显示新版版本号、“更新”按钮及发布页链接。点击“更新”会重新获取最新版，按 Windows 的 x64、x86 或 ARM64 架构下载单文件程序，校验文件大小、SHA-256 和程序架构后退出、替换并重启，保留当前程序路径及名称。下载失败不影响当前程序，新版无法启动时会尝试恢复旧程序。更新前请勾选“记住连接配置和账号”以保留当前配置；自动更新适用于发布版单文件程序，源码运行时请使用发布页下载。网络异常不会影响启动和转发服务。

程序位于 `C:\Program Files` 等受保护目录时，更新包会先下载到用户临时目录，再由 Windows 提示管理员授权。只有安装进程提权，新版仍以原用户和原权限启动；取消授权不会退出或替换当前程序。已选择记住的配置也会由安装进程一并保存。

## 从源码运行

在 Windows 上安装 .NET 10 SDK，然后在仓库根目录执行：

```powershell
dotnet run --project .\Dom2API\Dom2API.csproj
```

发布为自带运行时的 Windows x64、x86 和 ARM64 单文件程序（需要 Git）：

```powershell
.\publish.ps1
```

发布结果统一放在 `publish` 目录，目标电脑无需另行安装 .NET 运行时。也可指定一个或多个架构：

```powershell
.\publish.ps1 -Architecture arm64
.\publish.ps1 -Architecture x64,x86
```

发布版本取当前提交历史中最近的 `v*` Git 标签，没有可用版本标签时，脚本会报错；构建前需确保已拉取相关标签和提交历史。
